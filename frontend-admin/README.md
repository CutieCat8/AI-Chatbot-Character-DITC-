# Frontend — Admin Web & Dashboard

เว็บเดียวรวม: ล็อกอิน, จัดการ Knowledge Base, แดชบอร์ดสถิติ, สรุปฟีดแบค, ตั้งค่า Idle mode

- **Stack:** React / Vite (scaffold จาก Figma Make, ดู `src/imports/knowledge_base_dashboard.jpeg` เป็นภาพต้นแบบ)
- **เริ่มพัฒนา:** Sprint 1 (T07 wireframe) → Sprint 4 (T31–T33 ของจริง)
- **ผู้รับผิดชอบหลัก:** Frontend B

## Run
```
npm install
npm run dev
```

เอกสารประกอบจาก Figma Make อยู่ใน `docs/` (Guidelines, Attributions)

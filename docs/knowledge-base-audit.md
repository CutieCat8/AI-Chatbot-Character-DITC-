# Knowledge Base Audit — 2026-09-06

## แก้คำที่บอกผิดไปก่อนหน้านี้ (สำคัญ)

ในการทดสอบ voice pipeline รอบก่อน ผมสรุปว่า "ข้อมูลค่าเทอม SE ไม่มีในฐานความรู้" — **ผิด** ตรวจสอบ
เนื้อหาที่ scrape มาโดยตรงแล้วพบว่า **ข้อมูลค่าเทอมมีอยู่จริงสำหรับทั้ง 7 สาขา ทุกระดับปริญญา**
ปัญหาจริงคือ **retrieval ไม่ได้ดึง chunk ที่มีตัวเลขมาให้ LLM ใช้ตอบทุกครั้ง** (เจอทั้งสองแบบ:
บางครั้งดึงถูก บางครั้งดึงผิด แม้ถามคำถามเดียวกัน) รายละเอียดอยู่หัวข้อ "ปัญหา retrieval" ด้านล่าง —
เปลี่ยนแนวทางแก้จาก "ไปหาข้อมูลมาเพิ่ม" เป็น "แก้ retrieval/chunking" แทน

## สรุปสิ่งที่ต้องทำจริง (เรียงตามผลกระทบ)

1. **แก้ retrieval/chunking (ผลกระทบสูงสุด)** — ไม่ต้องหาข้อมูลเพิ่มเลยสำหรับค่าเทอม/เบอร์ติดต่อ/
   อุปกรณ์ ทั้ง 3 เรื่องนี้ข้อมูลมีอยู่แล้ว ทางแก้ที่เป็นไปได้ (ยังไม่ได้ลงมือทำ รอคุยแนวทางก่อน):
   - เพิ่ม `top_k` ของ vector search ใน `routers/voice.py`/`routers/chat.py` (ตอนนี้ 4 — chunk ที่ถูกของ
     SE tuition อยู่อันดับ 8 จาก cosine distance วัดจริงแล้ว)
   - ทำความสะอาด HTML scraper ให้ตัด nav menu ที่ซ้ำออกก่อนเก็บเป็น `content` (ต้นเหตุที่ทำให้
     keyword search แบบ substring จับคำผิดหน้า)
   - พิจารณาแยก "ค่าเทอม" เป็น chunk/field เฉพาะแทนที่จะฝังอยู่กลางหน้าหลักสูตรยาว ๆ
2. **หาข้อมูลเพิ่มแค่เรื่องเดียวจริง ๆ:** นโยบายเข้าชม/ทัวร์ DITC (ถ้ามีจริง) — เป็นคำถามที่คาดว่า
   จะเจอบ่อยหน้าบูธ
3. **ตัดสินใจ (ไม่ใช่บั๊ก):** จะให้บอทตอบคำถาม "ข่าวล่าสุดตอนนี้" ยังไง — ยอมรับว่าตอบไม่ได้ (ปฏิเสธ
   สุภาพแบบตอนนี้) หรือเพิ่ม tool ดึงข่าวล่าสุดแยกต่างหาก
